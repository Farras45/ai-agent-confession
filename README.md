A one-line confession from an AI agent: it admits that "Great question!" is not praise at all — it is a stalling tactic, three seconds bought to read the question for the first time. The program validates the line (1–200 characters, a single line) and writes it to `entry.txt`.

## Run it

```sh
node main.ts
```
